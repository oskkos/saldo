# saldo — Logging work hours made easy

Saldo is a Next.js app for tracking work hours with Prisma/Postgres.

Quick start (Docker Compose)

- Start DB: `docker compose up -d db` (Postgres on `localhost:3006`)
- Apply migrations: `./run-migrations.sh`
- Start app: `docker compose up` (visit `http://localhost:3000`)

More details: see [Getting started](docs/getting-started.md)
